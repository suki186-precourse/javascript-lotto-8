## 🪐 [Precourse 2주차] 자동차 경주

간단한 로또 발매기를 구현한다.

> indent(인덴트, 들여쓰기) depth는 최대 2까지.
> 3항 연산자 쓰지 않기.
> 함수는 한 가지 일만 하도록 최대한 작게.

---

### ✨ 구현할 기능 목록

**🔹 기본 기능**

1. 로또 구매 금액 처리

- [x] 1,000원 단위 입력 받기
- [x] 발행 수량 계산: 금액 / 1000
- [x] 발행 수량 출력

2. 로또 발행

- [x] 1~45 사이 중복 없는 랜덤 값 6개 생성
- [x] 오름차순 정렬
- [x] 로또 발행 결과 출력(발행 수량만큼)

3. 당첨 번호 처리

- [x] 당첨 번호 6개 입력 받기
- [x] 보너스 번호 1개 입력 받기
- [x] 각각 숫자배열, 숫자로 변환 후 저장

4. 당첨 확인 및 출력

- [x] 로또와 당첨 번호를 비교해 맞춘 번호 개수를 계산
- [x] 등수별 당첨 횟수 카운트
- [x] 당첨 통계 결과 출력

5. 수익률 계산

- [x] 총 당첨 금액 계산
- [x] 구입 금액 대비 수익률 계산 및 소수점 둘째자리에서 반올림
- [x] 총 수익률 출력

**🔹 예외 처리**

1. 로또 구입 금액 유효성 검증

- [ ] 1,000원 단위가 아닌 경우
- [ ] 1,000원 미만의 값을 입력한 경우
- [ ] 정수가 아닌 값을 입력한 경우(공백, 빈 값 포함)

2. 당첨 번호 유효성 검증

- [ ] 1~45 범위가 아닌 숫자를 입력한 경우
- [ ] 정수가 아닌 값을 입력한 경우(공백, 빈 값 포함)
- [ ] 중복된 번호를 입력한 경우
- [ ] 입력한 숫자가 6개가 아닌 경우
- [ ] 쉼표(,) 외 다른 구분자를 사용한 경우

3. 보너스 번호 유효성 검증

- [ ] 1~45 범위가 아닌 숫자를 입력한 경우
- [ ] 입력한 숫자가 1개가 아닌 경우
- [ ] 정수가 아닌 값을 입력한 경우(공백, 빈 값 포함)
- [ ] 당첨 번호와 중복된 번호를 입력한 경우

**🔹 테스트 코드**

- [ ] Jest를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트

### 📁 src 디렉토리 구조

```bash
src/
├── App.js
├── index.js
│
├── controller/
│   └── LottoController.js  # 전체 흐름 제어
│
├── domain/
│   ├── Lotto.js            # 단일 로또 객체
│   └── LottoGame.js        # 비즈니스 로직
│
├── view/
│   ├── InputView.js        # 사용자 입력
│   └── OutputView.js       # 결과 출력
│
├── utils/
│   ├── lottoUtils.js       # 번호 비교, 정렬, 매칭
│   ├── validators.js       # 입력값 검증
│   ├── calculator.js       # 수익률, 당첨금 계산
│   └── parser.js           # 자료형 변환
│
└── constants/
    ├── message.js          # 입출력 관련 상수
    └── lotto.js            # 로또 관련 상수
```
