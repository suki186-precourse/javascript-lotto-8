## 🪐 [Precourse 3] 로또

간단한 로또 발매기를 구현한다.

> indent(인덴트, 들여쓰기) depth는 최대 2까지.
3항 연산자 쓰지 않기.
함수는 한 가지 일만 하도록 최대한 작게.
> 

---

### ✨ 구현할 기능 목록

**🔹 기본 기능**

1. 구입 금액 입력

- [ ] 1000 단위의 구입 금액 입력 받기
- [ ] 구매 개수 계산

2. 로또 생성 및 출력
- [ ] 1~45 사이의 랜덤값 생성 함수 구현
- [ ] 6개 숫자로 이루어진 로또 배열 생성 후 오름차순 정렬
- [ ] 구매 개수만큼 출력

2. 당첨 및 보너스 번호 입력

- [ ] 당첨 번호 입력
- [ ] 보너스 번호 입력

3. 당첨 판별

- [ ] 당첨, 보너스 번호와 일치하는 번호 개수 계산
- [ ] 등수별 개수 계산 및 출력

4. 수익률 계산

- [ ] 구입 금액, 상금 기준 수익률 계산 (둘째자리 반올림)

**🔹 예외 처리**
1. 구입 금액 유효성 검사

- [ ] 숫자가 아닌 경우
- [ ] 1,000원 단위가 아닌 경우
- [ ] 공백, 빈칸인 경우

2. 당첨 번호 유효성 검사

- [ ] 1~45 사이의 숫자가 아닌 경우
- [ ] 6개가 아닌 경우
- [ ] 중복된 숫자가 있는 경우
- [ ] 구분자가 ,가 아닌 경우
- [ ] 공백, 빈칸인 경우

3. 보너스 번호 유효성 검사

- [ ] 1~45 사이의 숫자가 아닌 경우
- [ ] 1개가 아닌 경우
- [ ] 공백, 빈칸인 경우
- [ ] 당첨번호와 중복된 숫자인 경우
